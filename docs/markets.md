# 数据观察：配置与维护

入口：`/markets/pig/`，导航名称为「数据观察」。其余栏目为公司财报、国际金融、数据源。

## 数据边界

站点只读取 `src/data/markets/` 内的公开来源清单、公告种子与采集快照。采集脚本的输入是允许列表中的外部 HTTPS 站点，没有私人知识库、转写文件或个人笔记的输入参数。私人知识库继续在原位置维护，不与站点内容同步。

公开快照字段按表严格校验。文章全文、个人解读、投资持仓、私密笔记不属于导出字段。不要把私人数据库或其附件放入本仓库，包括 `public/`、`src/content/` 或 Actions artifact。

## 已接入的数据

| 来源 | 当前用途 | 口径 |
| --- | --- | --- |
| 农业农村部畜牧兽医局周报 | 生猪、仔猪、猪肉、玉米、豆粕、育肥猪配合饲料折线图 | 全国周度、元/公斤；横轴为采集日期 |
| 东瑞股份官网 | 定期报告、销售简报、投资者关系文件索引 | 标题、发布日期、文件原链接 |
| 新浪财经牧原公告转载 | 牧原公告索引，列表最近三页 | 明确标注转载；另保留巨潮正式报告种子 |
| Federal Reserve 货币政策 RSS | 议息声明、经济预测、会议纪要、政策公告 | 保留英文原标题，界面显示北京时间 |
| Federal Reserve FOMC 日历 | 未来议息会议 | 最后一个会议日，美国东部日期；不推定决议内容 |

26 个来源入口中，8 项采集器已经接通。其余官方和商业网站是可直接访问的入口，尚未接入其完整数据。省级每日现货、存栏、能繁母猪、屠宰、期货等不能当作已自动采集。商业付费数据不在公开快照中。

新增中国养猪网／玄田数据公开全国外三元日度报价，以及国家统计局流通领域外三元旬均价。两种口径分别展示，不与农业农村部周价拼接。中国养猪网只取无需登录的当前公开报价；会员历史不采集。数据源页面明确标识已自动接入的部分。

截至 2026-09-22，生猪周价共 453 期，跨度 2014-09-03 至 2026-09-17；其中 2014 年仅 2 期，2015—2016 年仍空缺，2017 年从 6 月开始。各项周度指标各自的缺期数量可能不同。外三元旬价 171 期（2021-10-20 至 2026-09-10）；外三元日价从 2026-09-22 起积累。这不是完整的 12 年日度或周度数据库，页面显式说明缺口并列出逐年期数。未验证数据不补零、不插值、不混用口径。

图表默认全部历史，提供近 12 年等视图与缩放滑块。视图筛选不会改变数据库；旧日期永久保留。来源更正同日数值时，旧值先归档到 `revisions`，再更新当前值。写入前检查历史身份集合不能缩小。完整公开归档可从 `/markets/archive.json` 下载，含修订；图表 CSV 包含当前所选指标和时间范围，含逐条来源链接。

Fed 已保存 2014 年以来 105 次利率决议及 49 次 SEP 点阵分布。会议列表按年份切换，摘要说明决策与利率目标区间；有原文明示时给出变动基点。仅关联同日官方 SEP，没有发布的会议明确标注，采集失败与未发布分开处理。点阵图用官方可访问数值表生成静态 SVG，支持负利率预测和不同期限的参会人数，不冒充未来政策承诺。

## 日常更新

```powershell
python -m pip install -r scripts/markets/requirements.txt
pnpm markets:test
pnpm markets:refresh
pnpm check
pnpm build
```

补历史：`python scripts/markets/refresh.py --backfill-pages 25 --backfill-history`。除周报目录外读取农业农村部历史发布日历、统计局公开目录及 Fed 年度档案。默认只抓当前目录和近期会议，并合并已有历史；补档不会清空快照。`price-seeds.json` 保留经核验的官方旧周报记录，仅补缺失日期。不要在每次定时任务中反复全量回补。

`snapshot.json` 按身份合并并原子替换。来源失败保留历史并标注错误；会议日历成功时整体替换，避免保留已取消或更改的会议。页面检查快照是否超过 24 小时，同时每条价格展示实际采集日期。博客首页增加最新报价、两家公司最新公告及 Fed 最近决议。首页每 5 分钟检查轻量 `/markets/latest.json`，回到页面时也检查；成功后原位更新，失败保留已载入数据并提示。这个检查不会触发源站爬取，源站采集仍由 3 小时工作流执行。

## GitHub Actions

`.github/workflows/markets.yml` 已配置每 3 小时检查一次（UTC 小时的第 17 分钟），支持手动运行。部署后才会生效；GitHub 的计划任务可能延迟，长期不活跃仓库也可能暂停任务。可在仓库 Actions 中查看状态。

任务仅提交 `src/data/markets/snapshot.json`，随后调用现有 Pages 部署工作流，构建该次提交。这样即使 `GITHUB_TOKEN` 提交不会触发另一次 push 工作流，也能完成数据更新发布。仓库若禁止 Actions 写入，需要在仓库设置允许该工作流写入；脚本不会强推或绕过分支保护。

全部来源不可用时仍发布带有故障状态的旧快照，Actions 显示警告；解析/导出校验失败时停止后续发布。需要了解具体故障时查看采集步骤日志，公开网页不展示响应体或本地错误路径。

## 性能处理

- 导航头像与背景图片使用 `public/assets/optimized/` 的适配尺寸版本，原素材保留。
- 执行 `pnpm optimize:images` 可重新生成；体积对比记录在本地 `.performance/image-savings.json`，不公开。
- 侧栏头像按 192/384/576 像素输出响应式图片。
- 叠加壁纸仅在启用该模式后加载当前设备对应图片；页面不可见时暂停轮播。
- 音乐音频设置 `preload=none`；取消第二套 CJK 字体的强制预加载。
- 图片模块扫描仅匹配图片扩展名。
- 数据栏目使用独立轻量布局与系统字体，图表模块只在图表进入视区时加载。复用 ECharts 的折线图所需模块，没有安装完整投研终端。
- 大量价格历史从独立 `/markets/prices.json` 按需读取并在同页复用；HTML 仅保留最近 12 期数值和静态折线，避免历史扩展后首屏膨胀。点阵图独立 SVG 延迟加载，博客首页不引入 ECharts。
- 数据页以完整页面导航切换，避免博客 Swup 主区域切换导致页面标题、栏目导航与脚本状态不一致。

## 修改与验证

- `src/data/markets/sources.json`：公开来源目录。
- `src/data/markets/report-seeds.json`：人工核实的正式报告入口；不填写未经核实的数字。
- `scripts/markets/refresh.py`：采集与导出校验。
- `scripts/markets/test_refresh.py`：离线日期、修订、故障保留和隐私边界测试。
- `src/pages/markets/` 与 `src/components/markets/`：看板页面和图表。

现有用户将 `src/styles/banner.css` 移至 `src/scripts/banner.css`；本次仅调整了 `main.css` 的引用以匹配现状，保留迁移内容。

复用项目与许可证：ECharts 6.0.0（Apache-2.0）；采集器直接读取官方公开页面，无需 API 密钥。AKShare 可供后续新增标准接口参考，当前未引入其依赖。站点发布不等于获得商业源的再分发授权，除公开日度报价外，商业历史及付费内容保留链接入口。
