> [!abstract] 今天的结论
> - 我们日常研究的“铜”，通常以阴极铜（精炼铜）为核心定价对象。
> - 铜矿石要经过采矿、选矿、冶炼和精炼，才能变成可供下游加工的阴极铜。
> - 铜价不能只看供需，还要同时观察库存、下游开工率、全球经济、美元和市场预期。
> - 同样属于“铜股”，矿山、冶炼厂和铜加工企业的盈利模式并不相同。

## 1. 为什么从铜开始学习有色金属？

我决定先从传统工业金属切入，而铜是很合适的第一站。它被广泛用于电网、汽车、家电、建筑、电子和机械制造等行业，需求覆盖面很广，因此铜价常被视为观察全球经济景气度的窗口，市场也常称铜为“铜博士”（Dr. Copper）。

不过，“铜能够反映经济”只是一种分析框架，不代表铜价可以准确预测经济。供给扰动、库存变化、金融交易和政策预期，都可能使铜价暂时偏离实体经济。

## 2. 我们说的“铜”是什么？

投资研究中经常提到的铜，主要指**阴极铜**，也叫精炼铜或精铜。它是铜精矿经过冶炼和电解精炼，或者铜矿石经过湿法浸出、电积后得到的高纯度铜。

阴极铜具有良好的导电性、导热性、延展性和耐腐蚀性，可以进一步加工成铜线、铜杆、铜板带、铜箔、铜管和各种铜合金。

按照手册采用的 GB/T 467-2010，阴极铜分为：

| 等级 | 牌号 |
| --- | --- |
| A级铜 | Cu-CATH-1 |
| 1号标准铜 | Cu-CATH-2 |
| 2号标准铜 | Cu-CATH-3 |

> [!note] 口径提醒
> 以上等级来自2020版《国际铜期货合约交易操作手册》引用的标准。做实际交易、交割或公司研究时，应再查询交易所及国家标准的最新版本。

## 3. 铜是怎样生产出来的？

铜产业链可以先记成下面这条线：

```text
铜矿石
  → 采矿与选矿
  → 铜精矿
  → 冶炼与精炼
  → 阴极铜
  → 铜杆、铜线、铜箔、铜管、铜板带
  → 电网、汽车、家电、建筑、电子产品
  → 废铜回收
```

### 3.1 火法冶炼

火法冶炼通常用于品位较高的硫化铜矿。简化流程是：

```text
铜精矿 → 闪速炉 → 冰铜 → 转炉 → 粗铜 → 阳极铜 → 电解 → 阴极铜
```

2020版手册称，火法冶炼产量约占当时世界铜产量的85%。这个比例是历史资料，不应直接当作当前数据使用。

### 3.2 湿法冶炼

湿法冶炼通常用于低品位复杂矿和氧化铜矿。简化流程是：

```text
铜矿石 → 浸出 → 含铜浸出液 → 富集 → 电积 → 阴极铜
```

手册将湿法描述为冶炼成本相对较低，但现实成本还取决于矿石性质、回收率、能源、药剂、项目规模和基础设施，不能只凭“火法或湿法”判断一家公司的成本高低。

### 3.3 什么是矿石品位？

“品位”指矿石中有价值金属的含量，不是最终阴极铜的纯度。

例如，一吨铜矿石的铜品位为1%，理论上含有：

$$
1\text{ 吨}\times 1\%=0.01\text{ 吨}=10\text{ 千克铜}
$$

如果回收率为90%，最终能够回收的铜约为9千克。

在其他条件相同的情况下，品位越低，为生产同样多的铜就需要开采、运输和处理更多矿石，单位成本通常更高。但判断矿山好坏还要结合回收率、剥采比、开采方式、副产品、基础设施和矿山寿命。

## 4. 全球精炼铜市场：一张历史快照

> [!warning] 不要把旧数据当成当前排名
> 以下内容来自2020版手册引用的2019年数据，作用是帮助理解产业格局，而不是描述2026年的最新市场。

| 观察维度 | 2019年手册列出的主要国家 |
| --- | --- |
| 精炼铜生产 | 中国、智利、日本、美国、俄罗斯 |
| 精炼铜消费 | 中国、美国、日本、德国、韩国 |
| 精炼铜进口 | 中国、美国、意大利、德国 |
| 精炼铜出口 | 智利、俄罗斯、日本 |

这里必须区分：**铜矿生产国**和**精炼铜生产国**不是同一个概念。一个国家可能拥有大量铜矿，也可能依靠进口铜精矿发展冶炼产能。

## 5. 铜主要用在哪里？

铜的主要用途包括：

- 电网、电线电缆和变压器
- 空调、冰箱等家电
- 汽车及新能源汽车
- 建筑管线和装饰材料
- 电子、机械与工业设备

手册引用的2019年中国精炼铜消费结构中，电力、空调制冷和交通运输是三个重要领域。由此可以先建立一条需求传导链：

```text
终端订单增加
  → 铜加工企业提高开工率
  → 阴极铜或废铜采购增加
  → 铜库存下降、现货成交改善
  → 铜价获得基本面支撑
```

## 6. 铜价由什么决定？

### 6.1 基本面：供给、需求与库存

铜价的基本面主要包括：

- **矿端供给**：铜矿产量、品位、罢工、天气、政策和新项目投产。
- **冶炼环节**：铜精矿加工费（TC/RC）、冶炼产能与检修情况。
- **下游需求**：电网、汽车、家电、建筑等行业的订单和生产情况。
- **显性库存**：交易所库存、保税区库存和社会库存。
- **再生铜**：废铜供应量、精废价差和进口政策。

通常而言，供给收紧或需求增加会对铜价形成支撑，库存持续上升则可能意味着阶段性供过于求。但必须结合价格所处位置和市场预期一起判断。

### 6.2 什么是铜下游开工率？

铜下游开工率衡量铜杆、铜管、铜板带箔、电线电缆等工厂实际使用了多少生产能力。

例如，某铜杆厂每月满负荷可生产1万吨，本月实际生产7000吨，则简化开工率为：

$$
\text{开工率}=\frac{7000}{10000}=70\%
$$

开工率上升通常说明生产变忙，但不能单独证明终端需求改善。还要同时检查订单、成品库存、原料库存和现货升贴水。

> [!tip] 更可靠的需求信号
> 开工率上升 + 订单增加 + 成品库存下降 + 原料采购增加，比单独观察开工率更有意义。

### 6.3 宏观面：“铜博士”看什么？

铜需求与全球制造业和固定资产投资关系密切，常见观察指标包括：

- 中国及全球制造业PMI
- 电网、基建、地产和制造业投资
- 汽车、家电等终端产销数据
- 中国社会融资规模
- M1与M2增速

社融反映实体经济从金融体系获得了多少资金；M1更接近可以立即支付和交易的活跃资金，M2还包括大量定期存款等潜在购买力。社融或M1改善并不等于铜需求已经发生，最终还要由订单、开工率和库存来验证。

### 6.4 资金面：美元、利率与预期

铜以美元计价，因此铜价与美元指数通常呈现一定负相关：美元走强时，非美元地区购买铜的成本上升，铜价容易承压；美元走弱时，铜价更容易获得支撑。

但这种负相关并不稳定。若美元上涨同时伴随强劲的全球需求，铜价也可能上涨。除了美元，还要观察全球利率、通胀预期、资金仓位和风险偏好。

## 7. 从铜价映射到铜股票

铜产业链公司至少分为三类：

| 公司类型 | 主要赚什么钱 | 关键变量 |
| --- | --- | --- |
| 铜矿山 | 金属售价减去采矿成本 | 铜价、权益产量、品位、回收率、现金成本 |
| 铜冶炼 | 加工费、副产品和规模效率 | TC/RC、硫酸及贵金属副产品、能源成本 |
| 铜加工 | 加工费和产品附加值 | 订单、加工费、产品结构、产能利用率 |

矿山公司的简化盈利框架是：

$$
\text{利润贡献}\approx（\text{铜价}-\text{单位成本}）\times\text{权益产量}
$$

因此，铜价上涨不代表所有“铜股”都同等受益。研究公司前，必须先确认它处在产业链的哪个环节。

## 8. 我的铜市场观察清单

以后观察铜市场，可以按照以下顺序：

1. 铜价处在什么位置，近期上涨或下跌由什么触发？
2. 铜矿供给有没有发生罢工、减产、品位下降或项目延期？
3. 铜精矿TC/RC在上升还是下降？
4. 国内外显性库存是在累库还是去库？
5. 下游开工率、订单和成品库存是否相互验证？
6. 电网、汽车、家电和建筑需求有没有改善？
7. 美元、利率、社融、M1/M2提供了怎样的宏观背景？
8. 相关公司属于矿山、冶炼还是加工环节？
9. 股价已经反映了多少乐观或悲观预期？

> [!check] 第1天真正学会的东西
> 今天最重要的收获不是记住某个国家的产量，而是建立了第一条研究链：**矿石品位与供给 → 冶炼 → 下游开工与订单 → 库存 → 铜价 → 不同类型铜企的利润**。
